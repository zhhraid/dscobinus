# Data

| Folder | Isi | Aturan |
|---|---|---|
| `raw/` | `train.csv`, `test.csv`, `sample_submission.csv` dari Kaggle | **Jangan diedit.** Hanya dibaca |

Hanya data dari panitia yang boleh ada di sini — **data eksternal dilarang**.
